# MultiScraperSearch

A tiny service that queries multiple sites and returns combined results.

### Quick start
Create a virtualenv and activate it, then install deps:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Run the app:

```bash
python main.py
```
Open http://localhost:8000/ and search for something.  
You should see combined results from multiple sites.
